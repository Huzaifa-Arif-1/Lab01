## What this lab shows
A SQLite database stores 4 certificate events. Two copies
(Registrar and Employer) are compared. When one copy is changed,
a conflict is detected. This shows that copies alone cannot decide
which record is correct.

- solution.py: source code
- week01_ledger.csv, alternate.csv: exported records
- Screenshots: terminal output of the commands

## Viva Answers
1. Who can correct the record?-- The authority designated by a documented policy.
2. Do multiple copies make a blockchain? --No, there is no consensus or validation.
3. When prefer a registrar database? --When there is one trusted authority.
